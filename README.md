# Green Channel Vendors Dashboard

Interactive dashboard tracking the green channel fruit vendors (Apple Fresh, Syed, DMC, Mr Fruiuts, VM agro, Srinivas GK) and their critical articles for the season.

**Live dashboard:** enabled via GitHub Pages once the first deploy completes — see the repo's "About" section on GitHub for the link.

Features: KPI cards, interactive filters (search, procurement type, critical-only, vendor chips), bar & donut charts, sortable data table with conditional formatting, and a per-vendor / master "notify critical articles" report you can copy to clipboard.
